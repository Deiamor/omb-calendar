OMB Calendar Privacy Policy

Last updated: 2026-10-21

Who uses this app

OMB Calendar is used only by its owner, with the owner's own Google accounts. It is not offered to other people.

What data it accesses

With the owner's consent, it uses the Google Calendar API to read and change the owner's calendars, events and event reminders.

How the data is used

Calendar data is used only to do what the owner asks, such as listing events or creating, updating and deleting events and reminders. The app runs on the owner's computer. No server is operated for it.

When the owner asks an AI assistant to work with calendar data, that data is sent to the AI model provider the owner has chosen (for example, OpenAI or Anthropic) to complete the request. Calendar data is not sold, not used for advertising, and not used to train AI models by this app.

Storage

Sign-in tokens are stored only on the owner's computer, in a file only the owner's account can read.

Removing access

Access can be removed at any time at https://myaccount.google.com/permissions, and by deleting the local token file.

Contact

Questions can be filed as an issue in this site's GitHub repository.

OMB Calendar 개인정보처리방침

최종 수정일: 2026-10-21

사용자

OMB Calendar는 소유자 본인만 자신의 Google 계정으로 사용합니다. 다른 사람에게는 제공하지 않습니다.

접근하는 데이터

소유자의 동의를 받아 Google Calendar API로 소유자의 캘린더, 일정, 일정 알림을 읽고 변경합니다.

데이터 사용 방식

캘린더 데이터는 일정 조회, 일정과 알림의 생성·수정·삭제처럼 소유자가 요청한 일에만 사용합니다. 앱은 소유자의 컴퓨터에서 실행되며, 이 앱을 위한 서버는 운영하지 않습니다.

소유자가 AI 비서에게 캘린더 데이터를 다루게 하면, 요청을 처리하기 위해 그 데이터가 소유자가 선택한 AI 모델 제공사(예: OpenAI, Anthropic)로 전달됩니다. 이 앱은 캘린더 데이터를 판매하거나 광고에 쓰거나 AI 모델 학습에 쓰지 않습니다.

저장

로그인 토큰은 소유자 컴퓨터에만, 소유자 계정만 읽을 수 있는 파일로 저장됩니다.

접근 해제

언제든 https://myaccount.google.com/permissions에서 접근을 해제하고 로컬 토큰 파일을 지우면 됩니다.
